Routine Admin Work Guide

October 21, 2026 · 3:00 PM PHT (UTC+8) · Fictional work sample

Use this guide when a request comes in, a document needs filing, or a recurring admin task is due.

Steps

  1. Log the request.

    Write down who asked, what they need, the due date, and who will handle it. Ask for missing details before treating the request as ready.

  2. Check the file.

    Confirm the date, reference, amount if relevant, and whether it is the latest version. Keep the original invoice or receipt unchanged.

  3. Save it in the right folder.

    Use the folder guide and file name format. Put an old working version in the archive and keep its record labeled.

  4. Get any decision needed.

    Send purchase, payment, and access requests to Alex. Do not treat a request, invoice, or draft as approval.

  5. Update the register and task list.

    Record the file path, owner, and status. Note the next check-in if someone still needs to respond.

  6. Close the task with a record.

    Mark it done only when the work is confirmed. Record the date and reference. Keep open items in the weekly update.

If something is missing

Leave the task open, write down what is missing, and ask the owner for it. If a due date may be missed, tell Alex before the deadline and suggest the next check-in.

Before sharing a file

Use the current file, check the recipient and access level, and test the link. Keep finance files limited to the people who need them.
