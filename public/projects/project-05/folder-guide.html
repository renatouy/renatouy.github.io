File names

Use Date_Document-Name_Reference_v01. Keep the reference when there is one. Put Draft in the name while a report is waiting for review. Templates do not need a date.

ExampleUse
2026-10-20_Supplier-Invoice_NS-1048_v01.htmlDated supplier record with its invoice reference.
2026-10-20_Stock-Check_v02.htmlCurrent version of the stock check.
2026-10-21_Weekly-Admin-Update_Draft_v01.htmlWorking report that has not been approved.

When a file changes

Keep the old version in the archive and update the register to point to the current file. Keep original invoices and receipts unchanged. Save notes or corrections separately.
